## 🎯 Objetivo do projeto;
Criar uma pagina HTML falando sobre um filme utilizando tags ensinadas em sala de aula utilizando imagens, textos, pastas e links corretamente.

## 🛠️ Tecnologias utilizadas;
HTML: Utilizada para criar e estruturar a página do filme. Visual Studio Code: Editor utilizado para escrever e editar os arquivos HTML. Navegador Web: Utilizado para visualizar e testar a página desenvolvida. Github: Para publicar e armazenar o projeto.

## 📌 Breve descrição da página desenvolvida.
A página desenvolvida apresenta informações sobre o filme escolhido, como título, imagem, sinopse e outras informações relevantes. O projeto busca criar uma página simples, organizada e visualmente agradável, utilizando HTML.
